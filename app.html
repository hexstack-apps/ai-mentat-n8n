        Initial start and login
        

          
First launch

          
When you open Mentat for the first time, n8n will start automatically on localhost:5678. The initial startup may take 30–60 seconds while n8n initializes its database and compiles the UI.


          
Creating your account

          
Once n8n loads, you'll see the setup screen. Create an owner account with your email and a password. This account is stored locally in the .n8n/ directory — it is not sent to any external server.


          
Subsequent launches

          
On every launch after the first, Mentat starts n8n and opens the UI automatically. Your workflows, credentials, and settings persist between sessions in the .n8n/ folder next to the application.


          
If n8n doesn't load

          
    
            
  • Check that port 5678 is not in use by another process
    • 
            
  • Restart the app — Mentat automatically kills stale n8n processes on startup
    • 
            
  • Check the Electron console (View → Toggle Developer Tools) for error messages
    • 
          

        

      


      

        How to provide n8n API key to Claude Code
        

          
Why an API key?

          
The n8n MCP server can work in two modes: documentation-only (no API key needed) or full access (requires API key). With full access, Claude Code can create, update, execute, and manage your n8n workflows directly.


          
Step 1: Generate an API key in n8n

          
    
            
  1. Go to the n8n tab in Mentat
    2. 
            
  2. Click your user icon (bottom-left) → Settings
    3. 
            
  3. Go to API section
    4. 
            
  4. Click Create API Key
    5. 
            
  5. Copy the generated key
    6. 
          


          
Step 2: Install MCP server with the key

          
    
            
  1. Go to the Claude Code MCP tab in Mentat
    2. 
            
  2. Paste the API key in the API Key field
    3. 
            
  3. Click Install n8n MCP Server
    4. 
          

          
The key is stored in your Claude Code configuration (~/.claude.json) as an environment variable for the MCP server.


          
Updating the key later

          
To change the API key: click Uninstall, enter the new key, then click Install again.

        

      


      

        How to set up licensing on self-hosted n8n
        

          
Community vs Enterprise

          
N8N Mentat runs the community edition of n8n, which is free and open-source under the Sustainable Use License. Most features work out of the box without a license key.


          
When do you need a license?

          
Some enterprise features require an activation key:

          
    
            
  • LDAP / SAML single sign-on
    • 
            
  • Role-based access control (RBAC) with multiple users
    • 
            
  • Source control (Git) integration in the UI
    • 
            
  • External secrets management
    • 
            
  • Log streaming
    • 
            
  • Worker mode for horizontal scaling
    • 
          

          
If you only use n8n for personal automation, you likely don't need a license.


          
Getting a license key

          
    
            
  1. Go to n8n.io/pricing
    2. 
            
  2. Choose a plan and sign up
    3. 
            
  3. You'll receive an activation key via email or from the n8n dashboard
    4. 
          


          
Activating the license

          
    
            
  1. Open n8n in the N8N Localhost tab
    2. 
            
  2. Go to Settings (gear icon, bottom-left)
    3. 
            
  3. Click Usage and plan
    4. 
            
  4. Enter your activation key and click Activate
    5. 
          

          
The license is stored in the .n8n/ directory and persists across restarts.


          
Environment variable activation

          
Alternatively, you can set the license key via environment variable before starting n8n. Add N8N_LICENSE_ACTIVATION_KEY=your-key to the n8n startup environment. In Mentat, this would require editing electron-main.js to add the env var to the n8n spawn call.
